# FEAT-001: FEAT-001 - Página inicial do portfólio, com navegação e seções identificáveis.

Status: DRAFT - human review required

## Acceptance criteria
- AC-001: Dado que o visitante acessa o endereço público, quando a página carregar, então deve ver o nome profissional e
- AC-002: um resumo de apresentação.
- AC-003: Dado que o visitante clica no menu Projetos, quando a ação ocorrer, então a página deve navegar até a seção
- AC-004: correspondente.
- AC-005: Dado que a página é aberta em largura de 390 px, quando o visitante navega, então o conteúdo não deve exigir
- AC-006: rolagem horizontal.
- AC-007: Dado que um link GitHub é acionado, quando aberto, então deve direcionar ao perfil correto em nova aba.
- AC-008: Dado que uma imagem informativa é exibida, quando lida por tecnologia assistiva, então deve ter texto
- AC-009: alternativo significativo.
